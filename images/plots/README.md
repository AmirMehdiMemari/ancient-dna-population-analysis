# Analysis Figures

This directory contains figures generated by the ancient DNA population analysis notebook.

## Main Figures

- `final_pca_pc1_pc2.png` — final PCA of the 616-sample analytical dataset
- `genetic_structure_through_time.png` — PC1 plotted against archaeological calendar year
- `pc1_by_archaeological_period.png` — PC1 distributions across archaeological periods
- `pca_explained_variance.png` — explained variance of the first principal components
- `kmeans_clusters_pca.png` — exploratory K-Means clusters displayed in PCA space
- `post_neolithic_pca.png` — PCA restricted to post-Neolithic individuals
- `pca_sensitivity_no_tw_no_lakenheath.png` — sensitivity analysis excluding selected site/representation effects

## Supporting Figures

- `chronological_distribution.png` — chronological distribution of ancient samples
- `samples_by_period.png` — sample counts by archaeological period
- `geographic_distribution_clean.png` — geographic distribution of the filtered dataset
- `pca_pc1_pc2.png` — earlier PCA visualization produced during exploratory analysis

The figures are generated from the analysis notebook:

`notebooks/01_ancient_dna_population_analysis.ipynb`
