# Data

This project uses the COMMIOS ancient DNA dataset for Britain and Ireland.

## Source

Metz et al. (2025), **COMMIOS: A curated dataset and web application for Integrative Analysis of Ancient DNA from Britain and Ireland**.

Zenodo dataset:
- Version DOI: `10.5281/zenodo.15536132`
- All versions DOI: `10.5281/zenodo.15536131`

License: CC BY 4.0

## Raw files used

The analysis uses the Human Origins dataset files:

- `COMMIOS_aadr_HO_v62.anno.gz` — archaeological and sample metadata
- `COMMIOS_aadr_HO_v62.geno.gz` — packed genotype data
- `COMMIOS_aadr_HO_v62.ind.gz` — individual information
- `COMMIOS_aadr_HO_v62.snp.gz` — SNP information

These raw files are not included in this GitHub repository because the genotype file is approximately 634 MB.

Place downloaded raw files inside:

`data/raw/`

## Processed files

The repository includes smaller processed outputs generated by the analysis:

- `britain_ireland_ancient_metadata.csv`
- `final_pca_results.csv`
- `period_pca_summary.csv`
- `analysis_summary.csv`

## Important Note

The archaeological period categories used in this project are broad analytical groupings derived from source metadata labels. They should not be interpreted as precise cultural classifications.
